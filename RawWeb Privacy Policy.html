RawWeb Privacy Policy

Last Updated: 2/2025

1. Data Handling

RawWeb is designed with privacy as its core principle:

  • 🛡️ No personal data collected (email, name, IP, etc.)
  • 🚫 No tracking of browsing activity
  • 🔒 No data sharing with third parties

2. Stored Information

Single stored value:
  • enabled - Boolean (true/false) tracking RawWeb status
  • Stored locally via Chrome's storage API
  • Never transmitted from your device

3. Permission Usage

Permission Purpose Data Access
declarativeNetRequest Block CSS/JS resources No content inspection
activeTab Reload current page Temporary tab access
storage Save user preference Only enabled state

4. Security Measures

  • 🔐 All operations occur locally on your device
  • 📜 Open-source implementation github
  • 🛡️ Follows Chrome's security best practices
